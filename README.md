# 🐈 Pokécat

Le Pokédex des chats croisés dans la rue.

Une petite app web à deux : chaque chat rencontré est « capturé » avec ses photos,
son nom, son adresse, un point sur la carte et son caractère (se laisse caresser ?
marrant ? gros lard ?). Le catalogue est commun et se synchronise en temps réel
entre les deux comptes.

## Démarrer

```bash
npm install
```

```bash
npm run dev
```
